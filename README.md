# multimodal-driving-data-processing
This repository contains the custom MATLAB code used for the preprocessing, synchronization, and integration of the multimodal data described in the associated Data Descriptor.
The raw data required as input to the processing scripts are not included in this repository and are not publicly available due to data-sharing restrictions. The publicly available dataset contains the resulting synchronized and processed data.

Code versions

Version 0 – Original processing workflow

This version contains the original MATLAB processing script used to preprocess, synchronize, and integrate the multimodal data associated with the original dataset.

Version 1.0 – Updated processing workflow

This version introduces an updated MATLAB processing script corresponding to the updated version of the multimodal driving dataset. The original processing script is preserved to ensure compatibility with the previous dataset version.
